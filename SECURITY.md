# Security

If you find a security problem in Histrova (for example a way it could run code it shouldn't, expose credentials, or change a repository without being asked), please **don't open a public issue**.

Report it privately instead: on this repository, go to **Security › Report a vulnerability** (GitHub's private reporting). Include what you found, how to reproduce it, and which version of Histrova and Git you use.

You'll get a reply as soon as possible, and credit in the release notes if you'd like.
